# color harmony

pick a color. get harmonious palettes instantly.

a tiny tool for designers and developers.  
choose any color and instantly see complementary, analogous, triadic and other harmony palettes.  
click any swatch to copy its hex. includes a simple contrast checker.

features:
- live color picker + hex input
- complementary, analogous, triadic, split-complementary, tetradic, monochromatic
- one-click copy
- wcag contrast checker
- fully client-side

stack:
- vite + react + typescript
- tailwind css
- colord
- lucide-react

structure:

src/
  App.tsx          - main color harmony tool
  index.css        - base styles
